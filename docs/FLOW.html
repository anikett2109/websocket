5. What each packet does on arrival

8. The sequence model in one picture

Market tick n100101102103104105106…112
Canonical chart stateS100S101S102S103S104S105S106…S112
FULL (every 2τ)—100→102102→104104→106…110→112
DEGRADED (every 6τ)—100→106…106→112
  • There is one clock for everything: a packet's seq is the tick whose canonical state it brings the client to, and baseSeq is the tick the client already has.
  • The frontend's rule is the same at every tier: apply the packet only if baseSeq == local seq. Otherwise it's a gap, so re-snapshot.
  • When nothing changed (the quiet regime between trades) nothing is sent, so the next base is the last delivered tick. A tier change keeps the same sequence space: the first packet in the new hub is a catch-up from the client's own tick.
